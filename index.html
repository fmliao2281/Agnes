老師 Google 雲端數據資料同步設定

本教學系統支援將學生的「Orientation 測試成績資料」自動同步寫入老師的 **Google 試算表 (Google Sheets)**。

網址會儲存在本機瀏覽器中，學生進行測驗後將直接上傳資料。

如何建立 Google Apps Script 自動寫入表單？

  1. 開啟新的 Google 試算表，命名為 Orientation 測試成績資料表。
  2. 於試算表中點選頂部選單 「擴充功能」 -> 「Apps Script」。
  3. 將預設代碼清空，並貼上以下代碼：
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  // 若為第一筆資料，自動設定欄位標頭
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["時間", "姓名", "科系", "學號", "測驗花費時間(秒)", "得分"]);
  }
  
  sheet.appendRow([
    new Date(),
    data.name,
    data.department,
    data.studentId,
    data.timeSpent,
    data.score
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
                       .setMimeType(ContentService.MimeType.JSON);
}
  1. 點選右上角 「部署」 -> 「新增部署」。
  2. 種類選擇 「Web 應用程式」，將「誰有權存取」改為 「任何人 (Anyone)」。
  3. 點選部署授權後，複製產生的 Web App URL，並貼回上方欄位即完成設定！
